# Flare Plugin SDK

Use the [Flare Plugin skill and authoring guide](skill/flare-plugin/README.md) to create,
extend, debug, and publish Flare Social Plugin API v1 adapters through GitHub.

The self-contained skill is in [`skill/flare-plugin/`](skill/flare-plugin/SKILL.md).
Follow the [installation instructions](skill/flare-plugin/README.md#install-the-skill)
for Codex or Claude Code, including GitHub installation, local/project setup,
verification, and updates. Copy the whole `flare-plugin` directory so its relative
references, types, templates, and examples travel with it. All documentation is
in English.

The complete Pixelfed sample is at
[skill/flare-plugin/examples/pixelfed](skill/flare-plugin/examples/pixelfed/README.md).
